# FastAPI Python Practice

A hands-on project for learning and practicing backend development with Python and FastAPI.

## 🚀 Technologies

- Python
- FastAPI
- Uvicorn
- Pydantic
- SQLAlchemy
- SQLite
- REST API
- JWT Authentication

## 📚 Topics Covered

- FastAPI basics
- Path and query parameters
- Request and response models
- Pydantic validation
- API documentation with Swagger
- APIRouter
- Dependency Injection
- CRUD operations
- SQLAlchemy ORM
- SQLite database
- Database relationships
- Authentication and authorization
- JWT
- Password hashing
- API error handling
